# Changelog - 2026-04-11

## Day 3: Logger Service Refactor + Log Generator Service

### Logger Service Refactor (`src/services/logger/`)

The logger service underwent a significant architectural refactor with environment-based configuration:

#### Configuration Overhaul
- Replaced hardcoded `config.py` settings with **environment variables**
- Configurable via `docker-compose.yml`: `LOG_LEVEL`, `LOG_RATE`, `LOG_TO_FILE`, `LOG_FILE_PATH`, `LOG_MAX_SIZE_MB`, `WEB_HOST`, `WEB_PORT`, `MAX_LOGS_TO_DISPLAY`

#### Code Refactoring
- **Deleted** `logHandler.py` — monolithic handler split into modular components
- **Added** `logger.py` — new `Logger` class with:
  - Custom log rotation logic (size-based, no external library dependency)
  - In-memory log storage (for web display)
  - Level-based filtering (`is_log_enabled()`)
- **Added** `web_server.py` — `LoggerWebServer` class providing:
  - `/api/logs` — JSON endpoint for recent logs
  - `/api/config` — JSON endpoint for configuration
  - Enhanced web UI with auto-refresh, color-coded log levels, sortable table

#### Sample Log Generation
- Built-in sample log generation with varying severity levels
- Random interval (5-20 seconds) between messages
- Messages include: memory usage, query times, record counts, system status

### New: Log Generator Service (`src/services/log-generator/`)

A new microservice that generates random log events to simulate a distributed system:

#### Features
- **Random log events** with configurable severity levels (DEBUG, INFO, WARNING, ERROR)
- **Service context**: Simulates logs from services like auth-service, api-gateway, worker, scheduler, cache
- **Template-based messages**: Dynamic values for memory usage, query times, record counts
- **Configurable interval**: Adjustable via `LOG_INTERVAL` environment variable (default: 2 seconds)

#### Files Added
- `src/services/log-generator/app.py` - Random log event generator
- `src/services/log-generator/Dockerfile` - Container configuration
- `src/services/log-generator/requirements.txt` - Dependencies

#### Configuration
| Service | Environment Variable | Default |
|---------|---------------------|---------|
| logGenerator | `LOG_INTERVAL` | 2 seconds |

### Architecture
```
┌─────────────────┐     logs      ┌──────────────┐
│ logGenerator    │──────────────▶│   logger     │
│ (random events) │               │ (LogHandler) │
└─────────────────┘               └──────────────┘
                                          │
                                    ┌─────▼─────┐
                                    │  app.log  │
                                    │ (rotated) │
                                    └───────────┘
```

### Web Interface
- Available at `http://localhost:8080`
- Displays logs from both logger and logGenerator services
- Shows unified view of all distributed system events
- Auto-refreshes every 10 seconds

### Docker Updates
- Added volume mount: `./logs:/logs` for persistent log storage
- Dockerfile updated with proper ENTRYPOINT/CMD separation
